# アンスリューム楽曲ソート

非公式ファンサイト。78曲、初期表示68曲。公式MV・ダンス・ライブ等へのリンク52曲。

曲の選択・検索・年代フィルター・上位件数指定・自動保存・戻る・ジャケット入りPNG・テキスト／共有リンクのコピーに対応。

## 起動

Node.js 20.9以上で `npm start`。http://127.0.0.1:4188/ を開きます。通常起動にパッケージのインストールは不要です。

## 曲目の方針と出典

[アンスリューム公式TuneCore](https://www.tunecore.co.jp/artists?id=530908&lang=ja)、各配信作品のLinkCore曲目、Apple Music、公式YouTube。ライブ限定曲は曲別のライブレポートも補助資料に使用。

SE、インスト、カラオケは除外。個人ソロは専用チェックボックスで切り替え。同曲の再録・短縮版は原曲へ統合。リミックス・別言語版は該当曲があるときだけチェックボックスを表示し、初期オフです。「超!!アンスデーム」、参加作品「シンデレラとよばないで (feat. アンスリューム)」も収録。「夢桜」「君夢物語」「ときめき死」はライブ記録を補助資料として追加。後二曲は旧体制ユニット曲です。個人ソロのオリジナル曲10曲は専用チェックボックスで切り替え（初期オフ）。「ときめき死」の月埜ヒスイ・ソロ版は旧体制ユニット版と別項目にして、それぞれの映像を区別しています。歌ってみた・踊ってみたの他アーティスト曲カバーは含めません。同名の別アーティストの作品は除外。

`dateKind: live` の日付は資料で確認できた公演日で、初披露日や発売日ではありません。音源未確認のライブ曲には無関係なジャケットを流用せず、曲名を表示します。曲別の出典は songs.js に保存。

## 確認記録

確認日 2026-10-11。公式YouTube公開一覧86本を取得し、選別した86本のプレイヤーメタデータを照合しました。短尺・トーク等は公開タイトルで分類しています。映像全編の視聴や非公開曲を含む網羅性の保証ではありません。

「アイデンティティクライシス」「夢桜」はユーザー確認により2019年の楽曲として収録。月日は未確認のためdateKind: year、date: 2019として管理し、2019年の絞り込み対象に含めます。補助資料の2022年の公演日を楽曲の年として使いません。

採否と統合先は catalog-audit.json と 楽曲確認台帳.md、動画の対応表は 動画確認一覧.md に記録しています。

## 検証・保守

`npm run check`、`npm test`。公開ファイルはこのフォルダーのみで動作します。調査キャッシュ・認証情報・node_modulesは公開しません。

保守用ルートで `node scripts/collect-wasuta-anthurium.mjs` → `node scripts/build-wasuta-anthurium.mjs` → `node scripts/audit-wasuta-anthurium.mjs` → `node scripts/package-new-covers.mjs アンスリューム楽曲ソート` → `node scripts/finish-wasuta-anthurium.mjs`。追加候補の判断は scripts/anthurium-supplemental.json に保持。再調査ではキャッシュを更新し、未一致候補の採否を確認してください。
